生成参数

温度 = 采样随机度。越低越稳、越可复现，语音包建议 0.45~0.55； 调高（0.7+）会有随机变化，但也可能吃字、含糊。

生成的文件名 = 自定义前缀 + 音色标识 + 原名， 例如 【我】君仪2_1分担.ogg。打包后前缀会显示在插件语音下拉里。

生成插件包

默认打包 output/ 里所有语音。 勾选具体音色则只打包那几个人物的（例如只打「君仪2」做一套单独包）。

勾选时：media/君仪2/…、media/未来1/…， 显示名变成 君仪2/1分担，下拉里一眼分开。 不勾选则全部平铺到 media/。

生成结构与露露的 SharedMedia_Rurutia 一致：.toc + MyMedia.lua（LSM:Register）+ ogg 音频，44100Hz 立体声。

它长这样

SharedMedia_WoWVoice/
├── SharedMedia_WoWVoice.toc
├── MyMedia.lua          ← LSM:Register("sound", ...)
└── media/
    ├── 君仪2/
    │   ├── 1分担.ogg
    │   └── 转阶段.ogg
    └── 未来1/
        ├── 1分担.ogg
        └── 转阶段.ogg

# MyMedia.lua 里的显示名：
LSM:Register("sound", "君仪2/1分担", ...)
LSM:Register("sound", "未来1/1分担", ...)

装完重启游戏，在 EXBoss / BigWigs / WA 的语音下拉里按人物分组选。

路径与依赖

自动扫描的默认位置：L:\工作流\VoicePackMaker\export。 只要目录里有 model.onnx + tokens.txt + lexicon.txt 就会被识别为可用音色。
